# CyberGuard

A Next.js + Tailwind CSS cybersecurity portfolio project.

## Run locally

1. Install Node.js 24+.
2. Open this folder in VS Code.
3. Open the terminal and run:

```bash
npm install
npm run dev
```

4. Open http://localhost:3000

## Build phases

- Phase 1: polished frontend (included)
- Phase 2: Firebase/Firestore database
- Phase 3: authentication + protected dashboard
- Phase 4: admin dashboard + CRUD
- Phase 5: validation, security hardening and testing
- Phase 6: GitHub + Vercel deployment

## Important

Do not put passwords, API keys, Firebase private keys, or other secrets directly in source code. Use environment variables.
